# God's Eye View: features, sources and agent tools

_Surveyed 2026-10-15 at commit `5b3e852` (v0.2.1) of [bilawalsidhu/gods-eye-view](https://github.com/bilawalsidhu/gods-eye-view). A local clone is at `~/Developer/personal/gods-eye-view`. To run it: `npm ci`, then `npm run dev` → http://localhost:4173. It works without keys._

GEV is a Cesium 1.124 + Vite browser globe:
- The server proxies are Vite middleware in `server/providers/*`.
- Voice control uses OpenAI Realtime over WebRTC.
- An MCP server answers data queries and returns share links.

**Licence:** the code is MIT, so it may be ported with attribution, like Argus. The datasets under `src/data/local_data/` and anything fetched at runtime are not MIT, and the Nepal flood pack is non-commercial.

**Rating premise:** the Value columns were rated while TAKIP was "personal use for now" and the roadmap parked space and cameras. With public free and paid plans:
- **Rated too low:** first-run missions, key setup, share links and feed-state honesty.
- **Now blocking:** the terms notes in §2. OpenSky, Open-Meteo, Google News RSS, TeleGeography (BY-NC-SA) and adsbdb route data all restrict commercial use.

**Path prefixes:** `G/` or `GEV/` is the GEV clone, and `T/` or `TAKIP/` is this repo.

**Port classes:**
- `data`: portable as is.
- `ux`: an interaction that ports to MapLibre with adapting.
- `render-cesium`: tied to Cesium, so only an approximation ports.
- For agent tools: **MA** (map-agnostic), **CN** (camera or navigation; needs a MapLibre equivalent) and **CO** (Cesium-only).

**What `.agents/skills/` holds:** only a maintainer skill for reviewing pull requests (`community-pr`). Nothing in it is portable. GEV's agent "skills" are its voice and MCP tools, in §3.

## 1. Features and interaction

**Two Takip constraints set the Value column more than GEV's demos do:**
- **Design contract** (`T/docs/design/README.md`): "Not a 'command centre' and not a sci-fi HUD". Scanlines, glows and corner marks are banned, and so is animating everything. That makes sensor looks, the military HUD, detection brackets, cyber sonar, the scope mask and split-flap chips **L as features**, unless the rule is changed first. The code already contradicts the rule in one place: the Style Studio ships a Scanlines slider (`T/src/components/shell/map-look/style-studio.tsx:192`).
- **Roadmap focus** (`T/docs/roadmap.md` "Decided"): wars and history first, then flights and ships, then weather and disasters. Space and cameras are parked (§6), and Takip is for personal use for now. CCTV and space rows are therefore capped at M, and onboarding and key-setup rows are rated low.

Takip runs MapLibre 6.7.0 with `three` and `satellite.js` already installed, and pitch already goes to 88° (commit 4d78c3a). Most `render-cesium` items therefore have a workable approximation.

### Engineering patterns worth stealing

- **Render holds** (`G/src/renderGovernor.js`): continuous rendering is a `Set` of owner IDs, not a counter, so a double hold or double release can't break the mode. A one-shot `requestRender(reason)` keeps a small ring buffer for diagnostics. In Takip: one shared rAF that runs only while a hold exists (interpolation, pulses, camera leaders, hover tips), instead of a separate loop per hook.
- **Share-link serialisation**:
  - **Codec** (`G/src/sharelink.js`, `G/src/data/layerState.js`): a deterministic v2 hash with a compact layer list and per-layer allowlisted options. An absent field means defaults and an explicit empty one means none; an unknown or duplicate layer token rejects the whole layer payload.
  - **Token ledger:** tokens are permanent, reserved in `G/src/data/layerStateTokenReservations.json`, and CI checks the ledger against `origin/main` so a token is never reused.
  - **Restore rules:** a link wins for that load without overwriting the recipient's saved preferences. Restore is split into lanes (visibility, options, camera, visual, map, panels), so a newer user action supersedes only the field it owns.
  - **Deferred target:** a target that hasn't arrived shows ACQUIRING under a deadline.
- **One "view" object for every producer** (`G/src/view/index.js`): camera, layers, style, map, marks and a followed entity in the share-link format. The UI, the MCP tools and embed mode all emit and restore it. TI could answer with a view link the same way.
- **First-run show policy** (`G/src/firstRunExperience.js`):
  - It shows once per browser session until the durable "don't show again" is ticked; `?welcome=0/1` overrides it, and a share link never shows it.
  - Picking a mission counts the same as clicking its toggles and persists nothing else: no detection, 3D or panel preferences the visitor didn't choose.
- **One feed-state normaliser** (`G/src/data/feedState.js`): heterogeneous stats map to seven states. Guidance states such as "zoom in" are not faults, and a fallback is never labelled live.
- **Reversible mode with dependency ownership** (`G/src/ui/contextSession.js`, `G/src/contextModePolicy.js`): a mode enables only the layers the user hadn't already turned on and releases only those. Changes the user makes inside the mode are recorded and replayed on exit. This is the right model for Takip's AI focus and any future "mode".
- **Camera ownership arbitration**:
  - `G/src/navigationPolicy.js`: navigation is stamped, the cockpit can refuse it, and a deferred flight rechecks its stamp before it flies.
  - `G/src/cameraVerbs.js`: one motion slot, and any pointer or wheel input cancels the automated motion.
  - Takip needs this as Follow, Replay, TI camera shots and tours start competing for the camera.
- **A renderer-free playback runner** (`G/src/director/playback.js`): adapter phases run in order (selectShot, applyVisual, applyLayers, travel, settle, hold, completeShot), with a cancellation token checked between phases. Seeking uses a pure sampler (`cameraAtProgress`, `sampleCameraMove`), so a backward seek doesn't depend on the previous pose. This fits Replay, History Play and the paleo story.
- **Bounded, versioned import documents** (`G/docs/SCENE-DOCUMENT.md`, `G/src/scenes/project.js`):
  - Size, depth, count and string limits are checked before JSON is applied, prototype keys are refused, and versions migrate one way.
  - An unreadable saved project blocks overwrites until the user re-imports.
  - Useful for workspaces and any import Takip adds.
- **Label and card host with budgets** (`G/src/overlays/worldOverlay.js`): sources supply bounded candidates; the host owns projection, placement, collision and hits. Each source has a cap, there is a shared ceiling, and protected (selected) entries bypass both. This suits Takip's DOM and canvas cards (camera previews, readouts) that MapLibre symbol collision doesn't cover.
- **Honest estimates in the UI**:
  - Launch replays are labelled RECONSTRUCTED ESTIMATE, and guessed CCTV headings draw dashed with "(ESTIMATED)" (`G/src/layers/cctv/headingConfidence.js`).
  - GNSS says "anomalies do not confirm interference", and analyst counts say "at least N" with coverage caveats.
  - Same spirit as Takip's "Off air" pins.
- **Small UX mechanics**:
  - **Click classifier** (`G/src/data/trackingClickGesture.js`): selection needs low pointer travel; deselection needs low travel and a short press, so a pan never deselects.
  - **ADD/KEEP hysteresis radii** (`G/src/data/cockpitAirLod.js`) stop flicker at a boundary.
  - **Stable colour per item** (`G/src/data/cctvViewshed.js`): a golden-angle hue over a sorted index.
  - **Bounded cache:** the terrain-height cache is an LRU capped at 20k entries.
- **Performance baseline recipe** (`G/docs/PERFORMANCE.md`): record the GPU string, use a fixed 1440×900 viewport at DPR 1 with the page focused, and take 5 s of scripted motion then 5 s at rest. Measure cold layer activation apart from warm switching, record live object counts, and treat a feed outage as missing coverage rather than a speed-up. Reusable for Takip's screenshot and performance checks.
- **Lifecycle discipline** (`G/docs/APPLICATION.md`): every constructor registers `defer(cleanup)` before its first `await`, teardown runs in reverse order, and an abort signal is threaded through. This addresses the unbounded in-memory caches listed in Takip's roadmap §6 "Code health".

### GEV tricks worth reusing on sources Takip already has

- **Interpolate flights instead of jumping.** GEV renders one poll behind (`RENDER_DELAY_SEC = 30` in `GEV/src/layers/flights/policy.js`) and dead-reckons with turn-rate arcs and slew-limited course (`GEV/src/data/motionModel.js`, adapted from skylight). Takip's flights jump each poll (`TAKIP/src/components/map/layers/live/use-flight-layers.ts`). Ships and transit would benefit too. The maths is short, but GEV's version is bound to Cesium types and needs porting.
- **Sticky metadata** (`GEV/src/data/aircraftMeta.js`). A field that resolved once is kept when a later OpenSky or adsb.lol snapshot omits it; a change still wins.
- **GNSS method.** Count a bad aircraft on NACp < 8, NIC < 7, or a GPS-loss flag. Skip TIS-B and MLAT-derived quality. Score as `100×max(0, bad−1)/total` with 2 % and 10 % bands, over a 30-min window across polls, needing at least 3 aircraft per 0.5° cell. This is more stable than one 2° snapshot.
- **Serve stale instead of relaying 429s.** On adsb.lol `/mil` failures, GEV returns the cached body with a STALE flag, so the UI never reads "failed" while it has data. Retry-After is clamped to 5–120 s.
- **AIS watchdog** (`GEV/src/data/aisWatchdog.js`). Report a silent feed at 120 s but recycle the socket only at 2.5× that. Back off 5 s / 15 s / 60 s / 300 s, then retry every 15 min. This respects AISStream's limit of one connection per key.
- **Overpass offload.** By default GEV never calls public Overpass. Roads and military areas come from OpenFreeMap vector tiles, and ALPR from DeFlock tiles. When Overpass is used, the bbox snaps outward to a ~5.5 km grid so the cached answer is a superset. A reply that hits the element cap is flagged SATURATED and re-asked for the exact view. Slow-changing features get a 30-day disk cache. Takip's `osm-webcams.ts` query takes 17–30 s and could use the same caching.
- **GRIB without the whole file.** Read the `.idx` (GFS) or JSON-lines index (IFS) and fetch only the needed messages with HTTP `Range`. Pick the forecast step nearest now, not f000. Companion fields fail soft.
- **nowCOAST seams.** GEV asks for global IR as one fixed 2048×1024 image because GeoServer's per-request contrast stretch leaves brightness seams between tiles. Its frame times come from the GetCapabilities time dimension, and exact-time images are cached 24 h. Check `weather/clouds` for the same seam issue.
- **CCTV heading parsing.** Accept bare cardinals ("West") only in dedicated direction fields. In names they are street names: 59 of ~1,000 Austin cameras were mis-oriented that way. Use an ID-hash fallback marked low confidence. Refresh Fintraffic stills on the station's 600 s cadence. The NSW image host needs a browser User-Agent.
- **adsbdb etiquette.** Ask for each key once ever. Keep a 24 h disk cache that includes 404s, at most 4 in flight, about 5/s.
- **Radio Browser resilience.** Discover mirrors. Replace a warm catalogue only when the refresh meets minimum query and station coverage; otherwise keep the last good one for up to 7 days.
- **Identifying headers.** Send `Client-Identifier` to Urban Sharing, `ET-Client-Name` to Entur and `Digitraffic-User` to Fintraffic. Allowlist upstream hosts and refuse redirects.
- **Budget governors.** TomTom's daily tile counter is persisted to disk and serves stale tiles over budget. Mapillary MVTs are trimmed in transit with `pbf` by dropping the z14 `image` layer, about 98 % of the bytes.
